# LinkedIn drafts

One draft per Guidelines section, plus a launch post and a "what we learned" post. Each is at most
**1,300 characters**, carries one concrete finding or artefact, and ends with the repository link.

The `.md.in` files are the sources; the `.md` files are generated by
`experiments/render_paper.py` (`make paper`) with every number injected from
`results/summary.json`. Edit the template, never the output: a hand-edited draft would drift from
the paper the first time an experiment is re-run. A test enforces the character limit, the
trailing link and the absence of unresolved placeholders.
