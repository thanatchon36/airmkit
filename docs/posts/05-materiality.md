MAS will not give you a materiality formula. Response to Feedback §7.19 says a prescribed methodology would not suit every institution. §4.12 names three axes - Impact, Complexity, Reliance - and leaves the combination to you.

So we published one, to be argued with: 23 signals, each citing the paragraph it derives from, an inherent and a residual tier, every score carrying its reasons, all in editable YAML.

Two things it taught us:

An agent raises the control set, not the tier. Moving a use case up a six-rung autonomy ladder, 7 controls first bind at the agent step - guardrail testing, tool permissions, trace monitoring - but only 1 of 4 use cases changed tier. Tier is dominated by consequence. A review process keyed on tier will miss the agent step entirely.

Under our defaults, no generative-AI use case can be rated Low: GenAI sets Complexity to High and the impact gate permits one level above Impact. We report that as a finding rather than tune it away. If you think the gate is wrong, it is one line of YAML.
